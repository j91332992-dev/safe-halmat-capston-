# P4 스피커 분리 진단

상시 운영 펌웨어가 아닌 수동 하드웨어 진단 소스입니다. 자동 부팅 확인음을 일반 펌웨어에 다시 추가하지 않습니다.

- `app_main.c`: 6개 I2S 출력 형식 비교 후 GPIO20/21/22 교차 검사. PCNT 입력 루프백으로 실제 핀 변화를 읽습니다.
- `gpio_only.c`: I2S/PCNT 초기화 없이 GPIO20/21/22를 하나씩 출력으로 두고 다른 핀의 레벨을 확인하는 독립 비교.
- `CMakeLists.txt`: I2S/PCNT 진단용 컴포넌트 설정. GPIO 전용은 SRCS를 gpio_only.c로, REQUIRES를 esp_driver_gpio로 지정합니다.
- 대상 핀은 사용자가 확정한 DFR1172 배선 GPIO20/21/22입니다. 다른 보드나 배선에 그대로 적용하지 마세요.

진단 업로드 중에는 안전모의 일반 기능이 실행되지 않습니다. 확인음은 1kHz/1초, PCM 진폭 6000으로 한 번씩 재생되므로 귀에서 떨어뜨려 비교합니다. GPIO 검사에서는 나머지 핀을 입력과 약한 pull-down으로 놓고 하나만 출력합니다. 다른 외부 장치가 해당 핀을 출력으로 구동하는 배선에는 사용하지 않습니다.

빌드 스테이지의 정상 소스·sdkconfig와 실제 동작 중 바이너리를 로컬 백업한 뒤 수동으로 진단 소스로 교체해 빌드합니다. 분석 후 정상 펌웨어와 소스를 복구합니다. 비밀 값이 포함될 수 있는 sdkconfig/플래시 덤프는 GitHub에 올리지 않습니다.

측정 범위와 결과는 `docs/P4_SPEAKER_SIGNAL_DIAGNOSIS_2026-10-10.md` 참조. GPIO 레벨과 카운트는 앰프 전압, 외부 단락 저항값, 실제 가청 출력을 증명하지 않습니다.
