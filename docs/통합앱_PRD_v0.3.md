# HANMIR 안전·근로 관리 통합 앱 PRD v0.3

작성일: 2026-10-09 / 상태: 구현 설계 전 검토 초안

v0.2를 대체하는 제품 요구사항이다. 기존 안전 기능과 작업자 권리 보호에 출퇴근, 자동 연차, 주 52시간, 다단계 전자결재, 팀 조직·채팅, 예상 급여를 포함한다. 이 문서의 기능은 개발 목표이며 구현 완료를 뜻하지 않는다.

## 1. 목적과 제품 구조

작업자는 본인 안전 상태, 근무·휴게·휴가 기록, 예상 급여와 권리 안내를 확인하고 신청·정정·신고를 할 수 있다. 팀관리자는 담당 팀의 기록과 신청을 검토하고 최고관리자는 최종 결재 및 운영 정책을 관리한다. 기존 관리자 안전 관제는 같은 앱에서 유지한다.

기존 React/TypeScript/Vite 소스와 FastAPI·DB를 확장한다. Capacitor를 사용해 하나의 공통 소스에서 웹·Android·iOS를 제공한다. Android는 APK/AAB, iOS는 IPA/TestFlight/App Store로 배포한다. iOS 빌드·서명은 macOS/Xcode 환경에서 수행한다. 플랫폼별 푸시·마이크·사진·파일 권한과 백그라운드 통화는 실제 기기에서 시험한다.

안전 기능은 기존 구현을 연동하는 전제로 계획한다. 신규 배선의 MAX17048 배터리, OV5647 영상, UWB 위치, 마이크·스피커 등은 서버가 제공하는 검증된 결과를 표시한다. 앱은 P4와 직접 연결하지 않는다.

## 2. 계정·역할·팀

공통 로그인에서 서버가 DB의 계정 역할, 조직·현장·팀 배정에 따라 화면과 API 권한을 결정한다. 사용자가 역할을 선택하거나 ID 접두사를 바꾸는 것만으로 권한을 얻지 않는다.

| 역할 | 범위 |
| --- | --- |
| 작업자 | 본인의 안전·근로·휴가·급여·신청과 소속 팀 채팅 |
| 팀관리자 | 지정 팀의 근무 현황, 신청 1차 검토, 점검·허가, 팀 공지 |
| 최고관리자 | 조직 내 최종 승인, 팀·관리자 지정, 운영 규칙과 권한 관리 |

상위팀/하위팀을 트리로 구성하고 순환 관계를 금지한다. 하위팀 열람 권한은 명시적으로 부여한다. 최고관리자도 다른 조직에는 접근하지 않는다. 팀관리자에게 개별 임금을 기본 공개하지 않으며 별도 급여 권한이 필요하다. 최고관리자 역할과 급여 정보 접근 권한도 분리해 설정할 수 있다.

소속·관리자 변경은 적용 시작/종료 시각을 기록한다. 진행 중 결재의 결재선은 제출 시 저장하고, 담당자 변경 시 권한 있는 재배정과 이력을 남긴다. 자가 결재를 금지하고 팀관리자 본인의 신청은 다른 승인권자로 전달한다.

## 4. 실시간 출퇴근·휴게 관리

작업자가 출근·퇴근·휴게 시작/종료를 기록한다. 홈에는 현재 상태, 출근 시각, 오늘의 실제 근로·휴게시간을 표시한다. 관리자는 권한 범위의 출근/휴게/퇴근/기록 확인 필요 인원을 실시간 확인한다.

출퇴근 시 서버 수신 시각과 실제 발생 시각, 입력 출처, 현장, 시간대, 온라인/오프라인 상태를 저장한다. 중복 누름·재전송은 동일 요청 ID로 처리한다. 오프라인 기록은 임시 저장 상태를 표시하고 재접속 시 동기화한다. 기기 시간과 서버 시간 차이·조작 의심은 검토 대상으로 표시한다.

퇴근 누락, 중복 근무 구간, 휴게 누락, 자정 넘김, 월/주 경계, 현장 이동은 사용자 정정과 관리자 검토를 지원한다. 관리자가 편집해도 원본 기록과 변경 사유를 보존한다. 미승인 연장근로도 실제 근무 원본을 삭제하지 않는다.

위치/UWB/QR 등 출근 확인 수단은 현장 정책으로 정한다. 기본은 앱 입력과 현장 배정 확인이다. 위치는 보조 근거로 제공하며 안전모 통신 종료나 구역 이탈을 퇴근으로 자동 확정하지 않는다. GPS 출근 확인을 추가할 경우 수집 목적·권한·오차·수동 정정 경로를 함께 제공한다.

## 5. 근무시간 자동 집계와 주 52시간

| 표시값 | 계산 원칙 |
| --- | --- |
| 실제 근로 합계 | 실제 근무 구간의 중복을 제거하고 실제 휴게를 제외 |
| 연장근로 | 적용 근무제도에 따라 일/주 기준 초과를 계산하고 중복 집계 방지 |
| 야간근로 | 적용 기준에 따라 22:00~다음날 06:00 구간을 분할 |
| 휴일근로 | 회사의 적법한 휴일 설정과 근로계약·법 적용에 따라 분류 |
| 주간 현황 | 실제 근로, 제도별 연장근로, 예정 근로, 확인 대기 시간을 구분 |

연장·야간·휴일은 서로 겹칠 수 있다. 같은 1시간이 야간·연장 모두에 해당해도 실제 근로 합계에는 1시간만 포함하고 수당의 중첩은 별도 규칙으로 계산한다. 주 52시간용 판단과 임금 가산용 연장 판단을 같은 단순 합계로 대체하지 않는다.

일반 근로시간제의 기준으로 1주 40시간 및 합의된 연장근로 12시간을 안내하되, 사업장 규모·근로 형태·유연근로제·법적 예외 등 적용 조건을 확인한다. 팀관리자/최고관리자 승인만으로 법정 한도를 초과할 수는 없다.

주 시작 요일, 법적 근무제도, 개인 소정근로일·시간, 현장 시간대, 휴일 달력을 버전 관리한다. 기준 미설정은 “확인 필요”로 표시한다. 연차 등 실제 일하지 않은 시간을 실제 근로 합계에 혼합하지 않는다.

일반 제도 대상의 알림 초안은 주 40시간·48시간·52시간 도달 및 예정 일정으로 초과 예상 시점이다. 알림은 중복 발송하지 않는다. 한도에 도달해도 타이머를 강제 종료하거나 기록을 잘라 실제 근무를 숨기지 않는다. 사용자와 관리자에게 조정 필요를 알리고 원본을 계속 남긴다.

## 6. 자동 연차 관리

작업자는 발생·사용·예약·취소·정정·소멸 예정·잔여 연차와 각 산정 근거를 확인한다. 연차는 거래 원장으로 관리하고 잔여 숫자만 덮어쓰지 않는다.

입사일, 출근율 산정 대상, 개근 조건, 근속기간, 소정근로시간, 적용 사업장 조건, 법령/회사 정책 버전으로 자동 산정한다. 일반적인 법정 안내는 1년간 80% 이상 출근 시 15일, 1년 미만 또는 출근율 80% 미만의 경우 1개월 개근 시 1일, 장기근속 가산과 한도를 포함한다. 정확한 발생·사용 기간·출근 간주·예외는 적용 시행 법령을 확인한 규칙으로 구현한다.

입사일 기준과 회계연도 운영 방식을 구분하고 법정 권리에 불리한 차이가 없도록 비교·정산 근거를 남긴다. 관리자 수동 조정은 사유·적용일·승인 이력이 필요하다.

연차·오전/오후 반차를 지원한다. 반차 차감량과 유급시간은 개인 소정근로시간/회사의 적법한 제도를 기준으로 설정한다. 모든 근로자를 8시간 근무로 가정하지 않는다. 소멸 예정 알림만으로 법정 연차 사용촉진 절차가 완료됐다고 표시하지 않는다.

결재 중 연차는 예약으로 구분하고 최종 승인 시 차감 상태를 확정한다. 반려·취소 시 예약을 반환한다. 잔여 부족·같은 날짜 중복·동시 신청을 서버 트랜잭션으로 검사한다. 미래 발생 예정 연차 사용은 회사 정책에 따라 별도 허용한다.

## 7. 전자결재

기본 결재선: 작업자 제출 → 팀관리자 검토 → 최고관리자 승인. 대상은 연차·반차, 출퇴근/휴게 정정, 연장근무 신청, 작업허가, 점검 보완 등이다.

상태: 임시저장 / 제출 / 팀검토 대기 / 최종승인 대기 / 승인 / 반려 / 보완요청 / 철회 / 취소요청 / 취소승인. 각 단계의 처리자·시각·의견·다음 담당자를 작업자가 확인한다.

팀관리자 승인만으로 최종 승인이라고 표시하지 않는다. 최종 승인 뒤 근태·연차 원장·허가를 함께 반영한다. 승인된 휴가 취소는 취소 결재로 처리하고 기존 신청을 지우지 않는다. 재시도·동시 승인·취소 경쟁을 막고, 제출 후 내용 변경은 새 버전으로 다시 검토한다.

담당자 부재 시 위임 기간·대리인·범위를 설정한다. 실제 관리자가 미배정이면 요청을 유실시키지 않고 최고관리자에게 배정 필요를 알린다. 법정 휴가 권리를 현장 사정만으로 일괄 금지하거나 승인 없이 자동 소멸 처리하지 않는다. 시기변경 등은 법적 요건에 따른 사유와 절차를 구분한다.

SOS와 급박한 위험의 작업중지·대피는 결재 대기 대상이 아니다. 즉시 신고/대피 후 보고한다.

## 8. 팀 채팅

팀 소속에 따라 채팅방 접근을 결정하고 팀관리자·최고관리자 지정 정보와 연결한다. 팀 채팅, 관리자 공지, SOS 대응 연락은 구분한다. 읽음 상태, 미확인 수, 푸시, 전송 실패·재시도, 허용된 파일 첨부를 제공한다.

일반 팀 채팅의 상위 관리자 참여는 명시적 구성원/권한으로 처리한다. 팀 이동·퇴사·계정 비활성화 시 접근을 회수하고 이전 대화 접근 정책을 고지한다. 메시지 수정·삭제는 정책과 이력을 남긴다. 급여·민감한 신고 자료를 일반 팀 채팅에 자동 게시하지 않는다. 채팅 읽음을 연차 승인·법정 교육 이수·SOS 접수로 간주하지 않는다.

## 9. 예상 급여 관리

작업자가 본인 계약의 시급 또는 월급, 근무 내역, 기본급·수당·조정 항목과 계산 기준을 확인한다. 임금 설정은 유효 시작일과 확인 상태를 저장한다. 작업자가 임의 입력한 금액은 개인 추정값으로 구분하고 회사 확인 임금과 혼합하지 않는다.

| 급여 유형 | 산정 방식 |
| --- | --- |
| 시급제 | 지급 대상 시간 × 적용 시급 + 해당 수당/유급 항목 ± 확인된 조정 |
| 월급제 | 계약 월 기본급 + 별도 지급 대상 수당 ± 정책에 따른 조정 |

월급제를 총 실제 근로시간×임의 시급으로 계산하지 않는다. 통상시급 산정은 계약 임금 구성과 월 통상임금 산정 기준시간을 확인하고, 모든 근로자에게 209시간을 고정 적용하지 않는다.

일반 가산 안내는 연장/야간근로 50% 이상, 휴일근로 8시간 이내 50% 이상·8시간 초과 100% 이상이다. 법 적용과 계약 조건을 확인한 뒤 중첩 가산·기본분 이미 포함 여부를 규칙으로 관리한다. 주휴·유급휴가·휴일·고정수당과 법정 가산분을 구분해 누락/중복을 방지한다.

출력은 “현재 기록 기준 세전 예상 급여”와 “예정 일정 포함 월말 예상”을 구분한다. 미확정 기록·부족한 임금 정보는 계산에 사용한 가정과 함께 표시하거나 계산 불가로 안내한다. 실제 임금명세서가 있으면 예상과 지급 확정액을 별도로 비교한다.

초기 범위는 세전 예상이다. 세후는 세금·보험·개인 조건을 검증한 기능이 추가된 경우에만 별도 추정으로 제공한다. 앱이 급여를 송금하거나 예상값을 확정 지급액으로 표시하지 않는다. 급여 열람·수정·내보내기 이력을 남긴다.

## 10. 안전·작업·근로자 권리 기능 유지

- SOS: 전송 중·서버 접수·관리자 확인 구분, 중복 사건 방지, 실패 시 전화 대안.
- 장치: 안전모/태그 구분, MAX17048 SOC와 최종 수신, 미수신을 0%로 표시하지 않음.
- 위치: 본인 UWB 위치·구역·신뢰도·갱신 시각, 위험구역 출입 정정 지원.
- 음성 통화: 휴대폰↔관리자 발신/수신/수락/종료, 권한·끊김·백그라운드 시험. 안전모 오디오 전환은 지원 경로 확인 후 제공.
- 점검: 체크리스트·불량·사진·제출·보완·관리자 확인.
- 허가/교육: 근거·유효 조건·이수 증빙 표시. 읽음만으로 법정 교육 처리하지 않음.
- 권리: 근로/휴게/휴가/임금/산재/대피 안내, 본인 기록 내보내기·정정·이의제기·상담 요청.
- 민감 신고: 이해충돌을 고려한 별도 접수자와 공개 범위. 피신고자에게 자동 공개 금지.

## 11. 화면 구성

작업자 하단 메뉴: 홈 / 근태·휴가 / 내 작업 / 소통 / 내 정보. SOS는 주요 화면에서 접근 가능하게 유지한다.

홈에는 출근/휴게/퇴근 버튼, 오늘 근무, 주간 시간, 연차 잔여, 안전 상태, 미처리 신청을 표시한다. 근태·휴가에는 근무 달력·시간 상세·연차 원장·신청·결재 상태를 제공한다. 내 작업에는 점검·허가·교육·내 위치를 제공한다. 소통에는 팀 채팅·공지·안전 알림·관리자 연락을 제공한다. 내 정보에는 예상 급여·권리 안내·기록 내보내기·프로필·장치 상태를 제공한다.

팀관리자는 팀 홈·출근 현황·검토함·팀 채팅·안전 업무를, 최고관리자는 기존 관제와 최종 결재·조직 설정·근로 규칙 관리를 제공한다. 본인이 작업자로도 배정된 관리자는 서버 허용 역할로 개인 기능을 사용할 수 있다.

## 12. 데이터와 계산 설계

기존 DB를 마이그레이션으로 확장한다. 주요 모델은 계정/역할, 조직/현장/팀, 팀 소속·관리자 배정, 장치 배정, 근무 구간·휴게·원본 이벤트, 정정 요청, 근무 일정·휴일·제도 정책, 연차 발생/사용 원장, 신청·결재 단계/결정, 교육·허가·점검·사진, 사건 처리, 채팅방·구성원·메시지, 임금 계약·수당 규칙·계산 결과, 권리 콘텐츠·감사 기록이다.

계산은 서버에서 수행하고 앱이 임의 계산한 값으로 DB를 덮어쓰지 않는다. 규칙·계약·조직 배정은 적용일과 버전을 저장해 과거 계산을 재현한다. 시간 정정 시 영향받는 집계·연차·급여를 재계산하고 확정된 월 자료는 변경 통지와 재확정 절차를 둔다. 근태 이벤트와 계산 결과의 출처를 연결한다.

서버 API는 본인/팀/조직 범위와 급여 등 별도 권한을 검사한다. 기존 관리자 전체 snapshot을 작업자 앱에서 숨기는 방식으로 접근을 제한하지 않는다. 민감 자료는 권한 있는 다운로드로 제공하고 첨부 형식·용량·접근 만료를 설정한다.

## 13. 개인정보·기록·실시간 기준

출퇴근·위치·사진·음성·급여·채팅은 목적과 처리 근거, 접근 범위, 보관/삭제 기간을 각각 정한다. 법정 보존 의무와 사용자 삭제 요청을 조정하고 이유를 안내한다. 작업 외 위치 추적은 기본 중지 방향으로 설계하고 현장 정책·처리 근거를 확인한다. 통화는 기본 녹음하지 않는다.

기록은 변경 전후·처리자·시각을 보존하고 본인이 내보낼 수 있다. 앱 기록만으로 법적 증거능력이나 위법 판정을 보장하지 않는다. 안전 알림으로 임금 공제나 징계를 자동 결정하지 않는다.

온라인 이벤트 수신 후 화면 반영 목표 2초, 일반 신청 접수 목표 3초. 백그라운드는 모바일 푸시와 필요한 네이티브 구성을 사용한다. 오프라인 제출은 동기화 대기로 표시하며 로그아웃/팀 변경 시 이전 권한과 푸시 연결을 회수한다.
