# 근로자 앱 실행 안내

기존 React/Capacitor 앱에 근로자 화면을 추가했습니다. 같은 로그인 화면에서 계정 역할에 따라 관리자 관제 또는 근로자 홈으로 이동합니다.

## 초기 근로자 계정

초기 계정은 `WORKER / 0000`이며 A현장의 `worker-001`에 연결됩니다. 서버 시작 시 계정이 없을 때만 생성하고 기존 계정의 비밀번호는 덮어쓰지 않습니다. 실제 운영 전에는 이 시험용 비밀번호를 변경하세요.

## 추가 근로자 계정 만들기

1. 관리자 앱의 **작업자 관리** 화면에서 해당 작업자의 **근로자 회원가입 초대 코드 만들기**를 누릅니다.
2. 생성된 코드를 해당 근로자에게 전달합니다. 코드는 24시간 동안 유효합니다.
3. 근로자는 로그인 화면에서 **근로자 회원가입**을 누르고 ID, 8자 이상 비밀번호, 초대 코드를 입력합니다. 가입 후 바로 근로자 화면으로 이동합니다.

관리자는 API로도 초대 코드를 생성할 수 있습니다. `worker_id`는 해당 현장에 이미 등록된 작업자 ID여야 합니다.

```http
POST /api/auth/worker-invites/worker-002
Authorization: Bearer <관리자 토큰>
```

초대 코드는 한 번만 사용할 수 있으며, 이미 계정이 있는 작업자는 다시 가입할 수 없습니다. 관리자 계정은 로그인 화면의 **관리자 회원가입**에서 만들 수 있으며, 가입과 함께 독립된 새 현장이 생성됩니다. 기존 현장 근로자는 초대 코드로 가입하세요.

## 현재 연결된 기능

- 본인 안전 상태, 위치·갱신 시각, 배정 장치 연결과 배터리 표시
- 본인 이벤트 목록, SOS 서버 접수와 관리자 확인 상태 표시 · 같은 현장 관리자 관제에 실시간 전달
- 작업 시작·휴게·재개·종료 기록과 오늘 작업 시간
- 관리자에게는 기존 관제 화면 유지

서버에 데이터가 없거나 장치가 끊기면 확인 불가로 표시합니다. 작업시간은 현재 서버의 시간대 기준으로 오늘 합계를 계산합니다.

## 추가 기능 (v1.7)

근로자 실시간 지도·월별 근로시간 달력·팀 채팅·교육/작업 허가 확인·소속/직책·시작 전 체크리스트·근무 배너·배터리 단계 경고를 구현했습니다. 관리자 설정 및 사용 범위는 [기능 확장 안내](근로자앱_기능확장_2026-10-09.md)를 참고하세요.

사진 점검·정정 요청·교육 강의/시험·앱 통화·OS 푸시·오프라인 동기화는 구현 범위에 포함되지 않았습니다.
