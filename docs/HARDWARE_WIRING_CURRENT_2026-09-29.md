# HANMIR 현재 하드웨어 배선도

작성일: 2026-09-29  
요약: 기존 HW의 실제 부품·배선·기능을 현재 제작 상태 기준으로 정리한 문서입니다.  
용도: 기존 설계 문서를 수정하지 않고, 현재 실제로 납땜되어 있다고 확인한 배선만 별도로 기록

> 이 문서는 현재 제작 상태를 정리한 별도 문서입니다. 기존 `HARDWARE_A_TO_Z_GUIDE.md` 및 기존 결선 문서는 수정하지 않았습니다.  
> **판단 기준:** 사용자가 확인한 실제 납땜 상태를 우선하고, 저장소의 `firmware/helmet_av_device/src/config.h` 및 관련 실행 코드는 별도의 "펌웨어 설정"으로 구분합니다.

## 1. 전체 전원·장치 연결

```text
[3.7V Li-ion 배터리]
          │
          ▼
   [TP4056 충전 모듈]
          │ OUT+
          ▼
      [전원 스위치]
          │ ON 상태
          ▼
    [승압 모듈: 약 5V]
          │
          ├── ESP32-S3 AV 장치
          │     ├── OV5640 카메라
          │     ├── INMP441 마이크
          │     └── MAX98357A 앰프 → 스피커
          │
          └── UWB 위치 장치

전기적으로는 모든 장치가 같은 GND 기준을 사용
```

여기서 "공통 GND"는 모든 GND 단자가 한 점에 직접 납땜되었다는 뜻이 아닙니다. 실제로 확인된 직접 배선과 전기적 공통 관계는 다음처럼 구분합니다.

| 구분 | 현재 확인된 내용 |
|---|---|
| 직접 납땜/연결 확인 | TP4056 OUT- → 승압모듈 VIN-, TP4056 OUT- → 스위치 3번, 승압모듈 VOUT- → ESP32-S3 GND, 승압모듈 VOUT- → UWB GND |
| AV 장치 내부에서 같은 기준 전위 사용 | ESP32-S3 GND, INMP441 GND, MAX98357A GND |
| 의미 | 위 경로들을 통해 전기적으로 같은 GND 기준을 사용함 |

| 부품 | 담당 기능 | 현재 상태 |
|---|---|---|
| 3.7V 리튬이온 배터리 | 헬멧 전체 전원 공급 | 사용 중 |
| TP4056 모듈 | 배터리 충전 | 사용 중, 보호회로 포함 여부는 모듈 실물/회로도 확인 필요 |
| 전원 스위치 | 헬멧 전원 ON/OFF | 사용 중 |
| 승압 모듈 | 배터리 전압을 약 5V로 승압 | 사용 중 |
| ESP32-S3 AV 장치 | 카메라·음성·Wi-Fi·서버 통신 | 사용 중 |
| OV5640 카메라 | 영상 촬영 및 화재·보호구 분석용 프레임 전송 | FPC 카메라 전용 커넥터 사용 |
| INMP441 | 작업자 음성 입력 | 사용 중 |
| MAX98357A | ESP32의 I2S 음성 신호를 증폭 | 사용 중 |
| 스피커 | TTS·경고·통화 음성 출력 | 연결됨 |
| UWB 태그 장치 | 위치 데이터 측정·전송 | AV 장치와 데이터선 없이 5V/GND만 공유하는 독립 장치 |
| UWB 앵커 | 위치 계산 기준점 | 안전모 내부 부품이 아니며 현장에 별도 설치, 현재 미설치 |
| 비상 스위치 | SOS 입력 | 현재 없음 |
| 배터리 분압 회로 | 배터리 잔량 측정 | 현재 없음 |

## 3. 전원부 배선

### 3.1 배터리와 TP4056

| 배터리 선 | TP4056 단자 | 역할 |
|---|---|---|
| 배터리 + | B+ | 배터리 양극 |
| 배터리 - | B- | 배터리 음극 |

```text
배터리 + ─────────────→ TP4056 B+
배터리 - ─────────────→ TP4056 B-
```

현재 사용 중인 TP4056 **모듈에 배터리 보호회로가 포함되었는지는 확인되지 않았습니다.** `OUT+/OUT-` 표기만으로 과충전·과방전·과전류 보호 기능 포함 여부를 확정하지 않습니다. 모듈 앞·뒷면 사진, 부품명 또는 판매처 회로도가 필요합니다.

### 3.2 TP4056, 전원 스위치, 승압 모듈

현재 전달받은 배선 기록은 다음과 같습니다.

```text
TP4056 OUT+ ─────────→ 스위치 1번
스위치 2번 ──────────→ 승압모듈 VIN+

TP4056 OUT- ──┬──────→ 승압모듈 VIN-
              └──────→ 스위치 3번
```

현재 실제 동작상 스위치를 켜면 승압모듈에 배터리 전원이 공급됩니다.

> 주의: 위 표의 1·2·3은 실제 연결 위치를 기록한 번호일 뿐, `COM/NO/NC`, LED GND 또는 접점 기능을 뜻한다고 확정하지 않습니다. 특히 **스위치 3번 단자의 기능은 제품 단자도 또는 멀티미터 측정 없이 확정할 수 없습니다.**

### 3.3 승압 모듈 출력

| 승압 모듈 단자 | 연결 대상 | 용도 |
|---|---|---|
| VOUT+ 약 5V | ESP32-S3 5V/VIN | AV 장치 전원 |
| VOUT+ 약 5V | UWB 5V | UWB 장치 전원 |
| VOUT- | ESP32-S3 GND | 직접 연결 확인 |
| VOUT- | UWB GND | 직접 연결 확인 |
| ESP32-S3 GND와 전기적으로 공통 | MAX98357A GND | AV 장치 내부 앰프 기준 |
| ESP32-S3 GND와 전기적으로 공통 | INMP441 GND | AV 장치 내부 마이크 기준 |

USB-C VBUS를 전원으로 사용할 수도 있지만 승압모듈 5V와 동시에 연결하지 않습니다. 두 전원 입력을 병렬로 묶기 전에는 보드의 역전류 방지 회로를 확인해야 합니다.

## 4. ESP32-S3 AV 장치 연결

### 4.1 ESP32-S3 전원

| ESP32-S3 핀 | 연결 |
|---|---|
| 5V/VIN | 승압모듈 VOUT+ 약 5V |
| GND | 승압모듈 VOUT- |

### 4.2 INMP441 마이크

| INMP441 핀 | ESP32-S3 연결 | 담당 기능 |
|---|---:|---|
| VCC/VDD | 3.3V | 마이크 전원 |
| GND | 공통 GND | 기준 전위 |
| L/R | GND | 왼쪽 채널 선택 |
| SCK/BCLK | GPIO1 | I2S 클럭 |
| WS/LRCL | GPIO2 | I2S 워드 셀렉트 |
| SD | GPIO42 | 음성 데이터 입력 |

```text
INMP441 VCC ──→ ESP32 3.3V
INMP441 GND ──→ 공통 GND
INMP441 L/R ──→ GND
INMP441 SCK ──→ GPIO1
INMP441 WS  ──→ GPIO2
INMP441 SD  ──→ GPIO42
```

INMP441 VCC에는 5V를 넣지 않습니다.

### 4.3 MAX98357A 앰프와 스피커

| MAX98357A 핀 | 연결 대상 | 담당 기능 |
|---|---|---|
| VIN | 승압모듈 약 5V | 앰프 전원 |
| GND | 공통 GND | 기준 전위 |
| BCLK | ESP32 GPIO41 | I2S 클럭 |
| LRC/WS | ESP32 GPIO40 | I2S 워드 셀렉트 |
| DIN | ESP32 GPIO39 | 음성 데이터 출력 |
| SPK+ | 스피커 + | 앰프 출력 |
| SPK- | 스피커 - | 앰프 출력 |

```text
ESP32 GPIO41 ──→ MAX98357A BCLK
ESP32 GPIO40 ──→ MAX98357A LRC/WS
ESP32 GPIO39 ──→ MAX98357A DIN

MAX98357A SPK+ ──→ 스피커 +
MAX98357A SPK- ──→ 스피커 -
```

`SPK-`는 GND에 연결하지 않고 스피커의 마이너스 단자에 연결합니다.

### 4.4 OV5640 카메라

기존 OV5640 카메라는 ESP32-S3 보드의 카메라 전용 커넥터에 FPC 플랫 케이블로 연결했습니다.

```text
OV5640 카메라
      │
      │ FPC 플랫 케이블
      ▼
ESP32-S3 카메라 전용 커넥터
      │
      └── 내부 DVP 병렬 인터페이스 GPIO 사용
```

외관상 카메라에서 ESP32-S3로 연결된 개별 점퍼선은 없지만, 카메라 신호는 보드 내부에서 여러 GPIO를 사용하는 DVP 병렬 인터페이스로 처리됩니다. 따라서 카메라를 연결했다고 해서 해당 GPIO들이 비어 있는 것은 아닙니다.

| DVP 신호 범주 | 역할 |
|---|---|
| D0~D7 | 카메라 영상 병렬 데이터 |
| XCLK | 카메라 입력 클럭 |
| PCLK | 픽셀 클럭 |
| VSYNC | 프레임 동기화 |
| HREF | 행 유효 신호 |
| SIOD/SIOC | 카메라 설정용 제어선 |

현재 펌웨어 `firmware/helmet_av_device/src/config.h`에서 확인되는 DVP 매핑은 아래와 같습니다. 이 표는 외부 점퍼선 목록이 아니라 보드의 카메라 커넥터와 펌웨어가 사용하는 신호 매핑입니다.

| 신호 | GPIO | 신호 | GPIO |
|---|---:|---|---:|
| XCLK | 15 | SIOD | 4 |
| SIOC | 5 | D7 | 16 |
| D6 | 17 | D5 | 18 |
| D4 | 12 | D3 | 10 |
| D2 | 8 | D1 | 9 |
| D0 | 11 | VSYNC | 6 |
| HREF | 7 | PCLK | 13 |
| PWDN | 미사용(-1) | RESET | 미사용(-1) |

현재 오디오 연결은 다음과 같이 구성된 것으로 기록되어 있습니다.

```text
INMP441:    GPIO1 / GPIO2 / GPIO42
MAX98357A:  GPIO41 / GPIO40 / GPIO39
```

사용자가 확인한 OV5640 FPC 연결, INMP441 배선 및 MAX98357A 배선은 현재 `config.h`의 핀 설정과 일치합니다. FPC 단자 번호별 회로 연결까지 검증하려면 ESP32-S3 보드의 회로도가 추가로 필요합니다.

## 5. 실제 HW와 펌웨어 설정 비교

| 기능 | 펌웨어에 있는 설정/코드 | 현재 실제 HW | 현재 통합 실행 상태 | 결론 |
|---|---|---|---|---|
| OV5640 | `config.h`의 DVP 핀과 카메라 초기화 코드 | FPC 전용 커넥터 연결 | `main.cpp`에서 `cameraBegin()` 호출 | 설정과 실제 HW가 일치 |
| INMP441 | GPIO1/2/42, I2S 입력 | 같은 핀으로 납땜 | `main.cpp`에서 `audioBegin()`/`audioLoop()` 호출 | 설정과 실제 HW가 일치 |
| MAX98357A | GPIO41/40/39, I2S 출력 | 같은 핀으로 납땜 | `main.cpp`에서 `speakerBegin()` 호출 | 설정과 실제 HW가 일치 |
| 버튼 | `BUTTON_PIN`이 GPIO0이고 `button_manager.cpp` 존재 | 버튼 없음, GPIO0 미배선 | 현재 `main.cpp`에서 `buttonBegin()`/`buttonLoop()`를 호출하지 않음 | 현재 사용할 수 없음 |
| 배터리 ADC | `BATTERY_ADC_PIN`이 GPIO3이고 `battery_manager.cpp`는 2:1 분압을 가정 | 분압회로 없음, GPIO3 미배선 | 현재 `main.cpp`에서 `batteryPercent()`를 호출하지 않으며 백엔드는 배터리를 `None`으로 저장 | 현재 값을 실제 잔량으로 사용할 수 없음 |
| UWB | 별도 `uwb_position_device` 펌웨어와 장치 ID 사용 | AV ESP32-S3와 데이터선 없음, 5V/GND만 공유 | 독립 Wi-Fi 장치로 서버 통신 | 기존 설계 구조이며 불일치가 아님 |

`config.h`에 핀 번호가 정의되어 있거나 관련 소스 파일이 존재한다는 사실만으로 해당 기능이 실제 HW에서 동작한다는 뜻은 아닙니다. 현재는 버튼과 배터리 ADC 기능 모두 실제 배선도 없고 통합 실행 경로에서도 사용하지 않습니다.

배터리 전압을 ESP32 ADC로 직접 읽는 방식은 GPIO 허용 전압 이하로 낮추는 **저항 분압회로가 필요**합니다. 반면 향후 검토 중인 MAX17048 같은 1셀 전용 연료게이지는 배터리 셀 전압을 전용 입력으로 측정하고 I2C로 결과를 전달하므로, ESP32 ADC용 저항 분압회로가 필수는 아닙니다. 단, MAX17048 모듈의 정확한 VCC/CELL 단자 구성과 3.3V I2C 로직 호환성은 해당 모듈 자료를 따라야 합니다.

## 6. UWB 장치 연결

### 6.1 현재 전원 연결

```text
승압모듈 VOUT+ 약 5V ──→ UWB 5V
승압모듈 VOUT-        ──→ UWB GND
```

현재 안전모의 UWB 태그 장치에는 승압모듈의 전원선과 GND만 연결되어 있습니다. AV ESP32-S3와 UART/SPI/I2C 같은 데이터선은 연결하지 않으며, UWB 장치는 자체 ESP32와 Wi-Fi 연결을 사용하는 독립 장치입니다. 이것은 배선 누락이 아니라 기존 시스템 구조입니다.

UWB 앵커는 안전모 내부에 배선하는 부품이 아닙니다. 현장 벽·기둥 등 고정 위치에 별도 전원과 함께 설치하고 좌표를 설정하는 기준 장치입니다. 현재는 앵커가 설치되지 않았습니다.

### 6.2 UWB 역할

| 구성 | 담당 기능 |
|---|---|
| UWB 태그 | 헬멧 위치 장치로서 거리·위치 데이터를 전송 |
| UWB 앵커 | 고정된 기준점으로 태그와의 거리를 측정 |
| Wi-Fi | UWB 장치에서 서버로 위치 데이터를 전송 |
| FastAPI 서버 | 위치 데이터 수신·저장·웹 전달 |
| 관리자 웹 | 작업자 위치와 이동 경로 표시 |

앵커가 설치되지 않은 현재 상태에서는 실제 삼각측량 위치를 확인할 수 없습니다. 펌웨어의 Mock 모드가 켜져 있으면 화면에 시험용 위치가 표시될 수 있습니다.

```text

   ↓ I2S 음성 데이터
ESP32-S3

```

## 8. 현재 설계에서 확정된 것과 확인이 필요한 것

### 확인된 내용

- INMP441은 3.3V와 GPIO1/2/42 연결
- MAX98357A는 5V와 GPIO41/40/39 연결
- UWB는 승압모듈 5V/GND만 연결
- 비상 버튼은 없음
- 배터리 ADC 분압 회로는 없음
- 배터리 → TP4056 → 스위치 → 승압모듈 구조
- 카메라·INMP441·MAX98357A의 실제 연결은 현재 AV 펌웨어 핀 설정과 일치
- UWB 태그는 AV ESP32-S3와 데이터선이 없는 독립 장치

### 재설계 전에 확인할 내용

- 전원 스위치 1·2·3번 단자의 실제 기능
- TP4056 모듈의 보호회로 포함 여부
- 승압모듈 무부하·부하 상태의 실제 출력 전압
- USB-C VBUS와 승압 출력의 역전류 방지 여부
- ESP32-S3 실제 보드 모델과 카메라 FPC 핀맵
- UWB 보드의 5V 입력 허용 여부
- 새 부품을 적용할 때 GPIO 충돌 및 전류 용량

## 9. 안전 주의

1. 배터리 전압을 ESP32 GPIO에 직접 연결하지 않습니다.
2. ESP32 ADC로 배터리 전압을 측정할 때는 저항 분압 회로가 필요합니다. MAX17048 같은 전용 연료게이지 방식은 ESP32 ADC 분압 방식과 다릅니다.
3. INMP441 VCC에 5V를 공급하지 않습니다.
