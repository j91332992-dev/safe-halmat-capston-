- 모바일·iPad 기준: `codex/hanmir-final-v1.5-build6-20261007` (`587a5a4`)의 `releases/HanmirSafety-account-signup-GitHub-ready-v1.5-build6-20261007.zip`

v1.5 브랜치의 최신 회원가입 앱은 일반 소스 폴더가 아닌 배포 ZIP 안에 있습니다. 해당 ZIP의 소스를 기존 PC 작업물과 병합했습니다. 최종 로컬 앱 버전은 **1.7.0, Android/iOS build 8**입니다. 브랜치 이름·커밋 날짜만으로 전체 하드웨어의 완성도를 판단하지 않았으며, 장치 실물 검증은 별도로 필요합니다.

## 통합한 기능

- 관리자 로그인·회원가입·ID 중복 검사, 신규 가입 시 독립 현장 생성
- 기존 계정 호환 및 새 계정별 비밀번호 솔트 적용
- 근로자 로그인·일회용 24시간 초대 코드 가입·역할별 화면
- 초기 근로자 `WORKER / 0000` (A현장 `worker-001`)
- 근로자 본인 안전 상태·위치·장치 연결·배터리·이벤트
- 작업 시작·휴게·재개·종료 및 오늘 작업 시간 기록
- SOS 저장·긴급 상태 반영·해당 현장 관리자에게 실시간 전송
- 다중 현장 API 및 관제 WebSocket 권한 분리, 근로자의 관리자 관제 접근 제한
- 기존 관제·음성·영상·UWB 기능 유지, P4 바이너리 영상·음성 업로드 개선
- v1.5 앱 아이콘·모바일 재연결·서버 설정, iPad 화면 방향·상태 표시줄·로컬 네트워크 설정

## 검증 및 실행 범위

- `npm run build`: TypeScript 및 웹 배포 빌드 통과
- 백엔드 전체 회귀 테스트: **92개 통과** (회원가입·현장 권한·P4·근로자 SOS·작업 상태 전이 포함)
- Android 및 iOS `npx cap sync` 모두 성공
- PC의 실제 `backend/safety.db`에 초기 근로자 계정이 있으며 기존 데이터를 유지
- 최신 설치용 APK/IPA는 아직 생성하지 않음: Android에는 JDK, iOS/iPad에는 Mac의 Xcode 및 서명 환경 필요
- 실제 안전모 통신·카메라·스피커·배터리와 iPad 실기기 검증은 아직 수행하지 않음

추가 요청에 따라 시작 전 체크리스트·팀 채팅·교육/허가·지도·달력을 구현했습니다. 사진 점검·앱 통화·정정 요청·OS 푸시·오프라인 동기화는 구현되지 않았습니다. [기능 확장 안내](근로자앱_기능확장_2026-10-09.md) 구현된 화면/API는 위 목록과 [근로자 앱 실행 안내](근로자앱_실행안내.md)에 명시했습니다. 기존 ZIP의 IPA는 이전 버전이며 이번 통합판 설치 파일이 아닙니다.
