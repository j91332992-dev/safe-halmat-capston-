## 확인한 문제와 수정

1. **위치 측정 카드**: 흰 배경에 흰 제목이 겹쳐 명암비 약 1.05:1이었다. 어두운 카드/밝은 제목으로 변경했다. 설계 오류 안내도 주황 계열 어두운 경고판으로 맞췄다.
2. **관리자 팀 채팅/교육 허가**: 이전 light 스타일의 더 높은 우선순위가 남아 있었다. 카드·제목·설명·입력창을 다크 스타일로 다시 지정하고 소속/팀/직책 입력이 모두 로드된 뒤 재확인했다.
3. **작업 상태 라벨**: 이전 `!important` 색상이 남아 새 어두운 배경에서 약 1.5:1 대비가 됐다. 종료/작업/휴게별 읽을 수 있는 색으로 수정했다.
4. **이벤트 로그**: 실제 19,173건이 한 번에 렌더되어 문서 높이가 1,036,287px에 달했고, 긴 문장은 오른쪽 439~481px까지 벗어났다. 50건씩 나눠 보고 휴대폰에서는 시간/등급/본문/작업자/상태/처리 버튼을 카드로 배치한다. 기존 기록은 삭제하지 않는다.
5. **버튼 숨김**: 기존 모바일 표는 상태와 확인·종료 열을 숨겼다. 카드 안에서 표시하도록 변경했다. 실제 확인·종료 버튼 높이 44px를 확인했으며 실제 처리는 누르지 않았다.
6. **연결 설정·알림 창**: 다크 배경으로 통일하고 안내문·입력값 대비를 보완했다. 설정창 버튼 최소 높이 44px를 적용했다.

## 수정 후 수치

- 재확인한 대시보드/설계/채팅/교육 허가/이벤트는 viewport=문서 폭=384px, 가로 넘침/잘림/명암비 3 미만 후보 0개. 반투명 배경·비활성 버튼·SVG의 모든 대비를 자동 검사한 것은 아니며 전체 접근성 인증을 뜻하지 않는다.
- 이벤트 페이지 이동: 당시 서버 화면에 표시된 54건 기준 1/2→2/2 전환, 마지막 페이지 4건, 첫 이벤트 내용 변경을 확인했다. 첫 페이지 상한은 50건이다. 이후 새 이벤트 수에 따라 페이지 수가 바뀐다.
- 알림 창: 폭 352px/내부 scrollWidth 350px로 가로 넘침 없음, 최대 50행 렌더.
- 연결 설정: 폭 360px. 기존 설정값은 변경/저장하지 않았다.
- 근로자 6개 메뉴는 모두 문서 폭 384px, 가로 넘침/잘림/명암비 3 미만 후보 0개. 작업 달력과 채팅 입력·로그아웃 버튼은 하단까지 스크롤하여 확인했다.

## 추가 요청: 위치 수렴 실패 알림 10분 제한

- 기존 코드가 `(현장, 작업자, 실패 문구)`별 5초 간격으로 `LOCATION_FAILED`를 만들었다. 수렴 실패와 앵커 부족 문구가 바뀌면 각각 다시 생성됐다.
- 이제 `(현장, 작업자)`별 600초에 1회만 생성한다. 다른 작업자/현장은 독립적이다. 원시 UWB 실패 원인과 마지막 유효 좌표 품질 정보는 매 주기 그대로 남긴다.
- 서버 재시작 후에도 DB의 최근 알림 시간을 확인해 남은 대기 시간을 이어간다. 매 주기 DB를 조회하지 않고 억제 기간에는 메모리로 처리한다.
- 설정: `UWB_LOCATION_FAILURE_NOTICE_SECONDS`, 기본 600. P4/UWB 재업로드는 필요 없다. 서버에 적용했다.
- 실시간 20초 확인: LOCATION_FAILED 총 19,152→19,152건. 태그 마지막 수신은 07:43:57.507→07:44:17.585 UTC로 계속 갱신됐다. 원시 로그 파일 수정 시각도 갱신됐으며 크기는 순환 저장으로 바뀐다. 초기 짧은 구간 확인이며, 이어서 실제 10분 경계까지 추가 확인했다.
- 새 시험 4개 통과: 599.999초 억제/600초 허용, 이유 변경 억제, 재시작 유지, 현장·작업자 분리, 1,000회 억제 중 추가 SELECT 없음.
- 관련 기존 UWB 품질 흐름 시험은 8개 통과/1개 실패. 실패는 품질 복구 직후 위치 허용 기대값이며, 수정 전 HEAD 코드로 격리 DB에서 재실행해 동일 실패를 확인했다. 이번 알림 변경으로 필터 판정을 바꾸지 않았다.

## 남은 확인과 범위 제한

- 점검 중 PC와 폰 모두 서버 응답이 수 초 이상 지연되는 구간이 있었다. 서버 재시작 뒤 일부 회복했지만 간헐 지연도 확인됐다. 알림 제한 적용 뒤 짧은 health 표본 3회는 모두 200(0~15ms)이었으나 장시간 안정화를 보장하지 않는다.
- 위치 실패 알림 간격 조정은 위치 수렴 원인 자체의 보정이 아니다. 앵커 신호/거리 품질/배치 검증은 별도다.
- 실제 Android 1개 기기, 기본 화면/글자 크기 기준이다. iPhone·다른 기기·큰 글자·TalkBack의 전면 검증은 포함하지 않는다.
- 폼 저장/위험 발령/메시지 전송, 영상 실제 재생, 사진 첨부 상태의 모든 조합을 이 UI 점검에서 실행하지 않았다.
