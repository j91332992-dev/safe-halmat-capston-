# HANMIR Android 앱 적용 및 모바일 UI 점검 — 2026-10-25

## 범위와 환경

- 브랜치: `integration/hanmir-final-prd-20261016`.
- 대상: Galaxy S24+ 실제 Android 앱, 관리자 및 근로자 화면. WebView 논리 화면 384×832 CSS px, 기기 스크린샷 1440×3120.
- 서버: 같은 LAN의 `http://192.168.0.40:8000`. IP가 바뀌면 앱 서버 설정을 변경해야 한다.
- 웹 개발 서버: `http://localhost:5174`. 네이티브 앱은 APK 내부 웹 자산과 LAN API를 사용한다.
- 사용자가 UWB 앵커를 임시 배치했으므로 이번 검증은 태그/앵커 수신만 대상으로 한다. 위치 정밀도 검증은 하지 않았다.
- 카메라/음성/통화/UWB 펌웨어 및 인식 임계값은 이번 UI 수정에서 바꾸지 않았다.

## 수정 내용과 원인

1. **근로자 하단 메뉴 글자 사라짐**: 데스크톱 사이드바 축소용 `nav button:not(.active){font-size:0}` 규칙이 근로자 메뉴까지 적용됐다. 해당 규칙을 `.sidebar` 하위로 제한하고 근로자 6개 메뉴의 글자 크기/터치 영역을 명시했다. 메뉴 이름과 현재 메뉴를 접근성 속성에도 표시한다.
2. **카메라 성능 수치 대비 부족**: 밝은 카드 배경에 모바일 공통 흰색 글자 강제가 겹쳤다. 모바일 성능 카드 배경을 어둡게, FPS/ms 수치를 밝게, 항목명을 충분히 밝게 조정했다. 2열 배치와 숫자 폭을 유지한다.
3. **장치 목록 잘림**: 760px 최소 너비 표 때문에 폰에서는 장치 상태/RSSI/최근 수신이 가로 스크롤 뒤에 숨었다. 600px 이하에서 항목명 있는 장치별 카드로 전환했다. 데스크톱 표는 유지한다.
4. **화면 이동 시 스크롤 위치 유지**: 관리자 경로 변경과 근로자 탭 변경 시 맨 위로 이동한다.
5. **화면 이동 시 통화 종료**: 대시보드에만 있던 통화 컴포넌트를 관리자 공통 영역에 유지하여 화면 전환에 따른 컴포넌트 해제/통화 종료를 방지한다.
6. **네이티브 상태 표시줄**: 관리자/로그인은 어두운 배경용 밝은 아이콘, 근로자는 밝은 배경용 어두운 아이콘을 적용한다.
7. 작은 화면에서 카메라 선택/상태 줄/빠른 제어의 줄바꿈, 근로자 카드/체크리스트/채팅 입력의 최소 폭과 박스 크기를 보완했다.

## 변경 전 실기기 검증

- 관리자 로그인 성공. 카메라 원본/분석 이미지 모두 실제 800×640 이미지를 로드했다.
- 지도는 가로 스크롤 없이 화면 폭 384px에 맞았다. UWB 태그와 앵커 4개 수신, 방향 표시를 확인했다.
- 최근 유효 좌표가 오래된 상태이며 서버에 위치 계산 수렴 실패가 있다. 수신 정상은 위치 정확도 정상을 뜻하지 않는다. 이번 UI 작업에서 지도/필터를 임의 보정하지 않았다.
- 근로자 로그인과 홈/지도/작업/채팅/알림/내 정보 접근을 확인했다. 작업 체크리스트 미선택 시 시작 차단을 확인하고 취소했다. 작업 기록을 임의 생성하거나 채팅을 보내지 않았다.
- 근로자 계정의 관리자 스냅샷 API 접근은 403으로 차단됐다.
- Android 양방향 통화 패킷과 음성 크기 갱신을 확인했고, 사용자는 “지직 안거림”으로 응답했다. 수치만으로 음질이 완벽하다고 판단하지 않는다.
