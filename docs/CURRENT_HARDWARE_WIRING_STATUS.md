# 현재 하드웨어 결선 상태

업데이트: 2026-08-07

이 문서는 실제 제작자가 보고한 현재 납땜 상태를 기록합니다. `현재 연결`과 `최종 통합 펌웨어 요구 핀`은 구분해서 봐야 합니다.

## 1. 전원 계통

```text
3.7V 리튬이온 배터리 + → TP4056 B+
3.7V 리튬이온 배터리 - → TP4056 B-
TP4056 OUT+ → 전원 스위치 COM
전원 스위치 NO → 승압모듈 VIN+
TP4056 OUT- → 승압모듈 VIN-
```

스위치 ON일 때만 승압모듈에 전원이 공급됩니다.

승압모듈 출력은 5V로 설정되어 다음처럼 분기되어 있습니다.

```text
VOUT+ → ESP32-S3 VIN(5V)
      → UWB 5V
      → MAX98357A VIN

VOUT- → ESP32-S3 GND
      → UWB GND
      → MAX98357A GND
      → INMP441 GND
```

모든 GND는 공통으로 연결되어 있습니다.

## 2. 현재 INMP441 결선

| INMP441 | 현재 ESP32-S3 연결 |
|---|---:|
| VDD | 3.3V |
| GND | GND |
| L/R | GND(Left) |
| SCK | GPIO4 |
| WS | GPIO5 |
| SD | GPIO6 |

## 3. 현재 MAX98357A 결선

| MAX98357A | 현재 연결 |
|---|---:|
| VIN | 승압모듈 5V |
| GND | 공통 GND |
| BCLK | GPIO15 |
| LRC/WS | GPIO16 |
| DIN | GPIO17 |
| SPK+ | 스피커 + |
| SPK- | 스피커 - |

`SPK-`는 GND에 연결하지 않고 스피커 양단을 `SPK+`, `SPK-`에 연결한 상태입니다.

## 4. 현재 UWB 전원 결선

```text
UWB 5V → 승압모듈 VOUT+
UWB GND → 승압모듈 VOUT-
```

UWB 통신선은 프로젝트 코드와 보드 구조를 확인한 뒤 연결 또는 내장 연결을 사용합니다.

## 5. 제작 진행 상태

- [x] 배터리 → TP4056 → 스위치 → 승압모듈 납땜
- [x] 승압모듈 → ESP32-S3 전원
- [x] 승압모듈 → UWB 전원
- [x] INMP441 연결
- [x] MAX98357A 연결
- [x] 스위치 ON 시 ESP32-S3 LED 및 부팅 확인
- [x] 스위치 ON 시 UWB LED 및 부팅 확인
- [ ] 카메라·마이크·스피커 GPIO 충돌 해소
- [ ] 최종 AV 펌웨어 업로드
- [ ] 마이크 녹음·스피커 음성·카메라 동시 동작 확인

## 6. 중요: 현재 GPIO 충돌

현재 납땜한 오디오 GPIO는 최종 OV5640 카메라 핀과 겹칩니다.

| 현재 오디오 신호 | 현재 GPIO | 같은 GPIO를 사용하는 카메라 신호 |
|---|---:|---|
| INMP441 SCK | 4 | CAMERA SIOD |
| INMP441 WS | 5 | CAMERA SIOC |
| INMP441 SD | 6 | CAMERA VSYNC |
| MAX98357A BCLK | 15 | CAMERA XCLK |
| MAX98357A LRC | 16 | CAMERA D7 |
| MAX98357A DIN | 17 | CAMERA D6 |

이 상태에서는 카메라, 마이크, 스피커를 같은 ESP32-S3에서 동시에 사용할 수 없습니다. 특히 GPIO16·17은 카메라 데이터 출력과 ESP32의 I2S 출력 설정이 충돌할 수 있으므로 전원을 끈 상태에서 재배선해야 합니다.

## 7. 최종 통합 펌웨어 기준 재배선

현재 `firmware/helmet_av_device/src/config.h`의 충돌 회피 핀은 다음과 같습니다.

| 장치 신호 | 최종 펌웨어 GPIO |
|---|---:|
| INMP441 SCK/BCLK | GPIO1 |
| INMP441 WS | GPIO2 |
| INMP441 SD | GPIO42 |
| MAX98357A BCLK | GPIO41 |
| MAX98357A LRC/WS | GPIO40 |
| MAX98357A DIN | GPIO39 |
| 비상 버튼 | GPIO0 |
| 배터리 ADC(분압 필수) | GPIO3 |

따라서 전체 기능을 유지하려면 다음처럼 옮깁니다.

```text
INMP441: GPIO4/5/6 → GPIO1/2/42
MAX98357A: GPIO15/16/17 → GPIO41/40/39
```

보드에서 GPIO1, 2, 39, 40, 41, 42가 실제 외부 핀으로 노출되어 있는지 회로도와 실물 라벨을 먼저 확인합니다. 노출되지 않았다면 임의로 펌웨어 핀만 바꾸지 말고, 카메라와 겹치지 않는 다른 노출 GPIO를 확정한 뒤 `config.h`를 함께 수정해야 합니다.

## 8. 스피커 치지직 현상 판단

현재 MAX98357A가 GPIO15/16/17에 연결됐지만 펌웨어는 GPIO41/40/39에서 I2S를 출력합니다. 따라서 앰프가 BCLK/LRC/DIN을 정상적으로 받지 못하는 것이 전원 투입 후 치지직 소리의 직접적인 원인 후보입니다.

재배선 후에도 부팅 순간 잡음이 남으면 다음 순서로 추가 조치합니다.

1. 부팅 즉시 I2S 핀 LOW 고정
2. 무음 DMA 버퍼 준비 후 I2S 시작
3. 가능하면 MAX98357A SD/EN 핀으로 초기화 중 음소거
4. 앰프 전원 근처 0.1uF와 100uF 디커플링 확인

## 9. 전원 안전 확인

- 승압 출력은 부하 연결 상태에서도 4.9~5.1V인지 측정합니다.
- 충전 중 안전모를 착용하거나 시스템을 장시간 운용하지 않습니다.
- TP4056 모듈이 보호회로 포함 제품인지 확인합니다.
- 배터리 팽창, 냄새, 발열이 있으면 즉시 전원을 분리합니다.
- 배터리 전압을 ESP32 ADC에 직접 연결하지 않습니다. 반드시 분압기를 사용합니다.
